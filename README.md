# AI-Based Road Hazard Prediction System

B.Tech CSE Final Year Minor Project (Aug–Nov 2026), scaling to Major Project (Jan–May 2027).

## Team
- Aishee — Integration, risk-prediction model, documentation lead
- Adrija — Hazard detection (computer vision)
- Debopriya — Data engineering (weather/geo), dashboard

## Project Summary
Detects road hazards (potholes, cracks) from images using computer vision, and predicts
hazard-prone zones using historical accident and weather data, visualized on a map dashboard.
